# Luca Patrignani

Personal academic website: **https://englpat.github.io/**

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. No frameworks, no build step.

## Structure

```
index.html            the whole page
404.html              "page not found" page
assets/
  css/style.css       styling
  js/main.js          menu, greeting and small interactions
  js/mesh.js          the interactive meshes (hero and elephant)
  fonts/              Inter font and its licence
  img/                photo, icons, preview image
robots.txt            for search engines
sitemap.xml           for search engines
google…html           site verification for Google Search Console
```

## Run locally

Open `index.html` in a browser, or run `python -m http.server` in this folder
and visit http://localhost:8000.
